=====================================================================
 ExtraKeyboard MK1 — ARDUINO IDE ILE FIRMWARE YUKLEME REHBERI
=====================================================================
Bu klasordeki "ExtraKeyboard_MK1" klasoru, Arduino IDE ile dogrudan
acilip yuklenebilen TAM firmware kodudur (PlatformIO'daki ile ayni).

---------------------------------------------------------------------
 1) GEREKENLER (bir kez kurulur)
---------------------------------------------------------------------
- Arduino IDE 2.x  (arduino.cc/en/software)
- ESP32 karti destegi:
    File > Preferences > Additional boards manager URLs kutusuna:
    https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
    Sonra: Tools > Board > Boards Manager > "esp32" (Espressif Systems) > Install
- Kutuphane:
    (Bu surumde harici kutuphane GEREKMEZ - duz LED kullaniliyor)

---------------------------------------------------------------------
 2) PROJEYI AC
---------------------------------------------------------------------
"ExtraKeyboard_MK1" klasorunu cift tikla > ExtraKeyboard_MK1.ino
(Arduino IDE klasordeki TUM .cpp/.h dosyalarini otomatik derler.)

---------------------------------------------------------------------
 3) KART AYARLARI — Tools menusu (KRITIK!)
---------------------------------------------------------------------
  Board              : ESP32S3 Dev Module
  USB Mode           : USB-OTG (TinyUSB)      <-- EN KRITIK AYAR!
                       ("Hardware CDC and JTAG" secilirse klavye/HID
                        HIC calismaz)
  USB CDC On Boot    : Enabled                <-- PC uygulamasi bunsuz
                                                  cihazla konusamaz
  Flash Size         : 16MB (128Mb)
  PSRAM              : OPI PSRAM
  Partition Scheme   : 16M Flash (3MB APP/9.9MB FATFS)
                       (veya baska bir 16M semasi — hepsi yeterli)
  Upload Speed       : 921600
  Digerleri          : varsayilan kalabilir

---------------------------------------------------------------------
 4) YUKLEME
---------------------------------------------------------------------
1. Kabloyu kartin "USB" etiketli USB-C konnektorune tak
   (veri kablosu olsun; mumkunse hub'siz, dogrudan bilgisayara).
2. Port sec: Tools > Port > usbmodem/COM... (ESP32-S3 olan).
3. Upload'a bas.

SORUN: "Failed to write..." / baglanti hatasi alirsan:
   - Karttaki BOOT dugmesini basili tut, RST'ye bir kez bas-birak,
     BOOT'u birak (boot modu). Portu yeniden sec, Upload'a tekrar bas.
   - Yukleme bitince program kendiliginden baslamazsa RST'ye bir kez bas.

---------------------------------------------------------------------
 5) ONEMLI NOT — USB KIMLIGI
---------------------------------------------------------------------
Arduino IDE, ozel USB kimligi (VID/PID/urun adi) bayraklarini menuden
AYARLAYAMAZ. Bu yuzden Arduino ile yuklenen firmware bilgisayarda
"ExtraKeyboard MK1" yerine genel "ESP32S3" kimligiyle gorunur.
SORUN DEGIL: PC uygulamasi bu durumu bilir — Espressif kimlikli tum
portlari dener ve el sikisma (CMD ID) yanitina gore dogru cihazi bulur.

"Gercek" kimligi (ExtraKeyboard MK1, 0x303A:0x82E1) istiyorsan
PlatformIO ile yukle:  proje kokunde  cd firmware && pio run -t upload

---------------------------------------------------------------------
 6) HIZLI DOGRULAMA
---------------------------------------------------------------------
- Yukleme sonrasi LED3 KIRMIZI yanar (PC uygulamasi bagli degil = normal).
- PC uygulamasini ac -> birkac saniyede LED3 YESIL olur.
- Seri monitorden (115200) su satirlar akar:  HB <sayi>  (kalp atisi)
